# Wall Map

A web app for collecting, sharing, and exploring personal route maps and points of interest.

Each user has a profile centered on an interactive map. They add **routes** from GPX files or Google Maps links, pin **points of interest** to memorable places, and enrich both with names, notes, and photos. Users can filter their collection, visit other people's maps, and follow fellow explorers.

Built with **Nuxt 4**, **MapLibre GL**, and **Supabase** (PostgreSQL + PostGIS).
